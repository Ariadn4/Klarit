## MODIFIED Requirements

### Requirement: 当前项目目录文件树

当窗口已绑定一个项目时，侧边栏的文件树视图 SHALL 以该项目的**项目目录**为根，像资源管理器一样直接列出该目录下的全部文件夹与文件，文件夹可展开/折叠以查看其子项。文件树 MUST 反映磁盘上的实际内容，对目录内的增删改在合理时延内更新。

- 无论项目含一个还是多个成员仓，文件树都以项目目录为唯一根，**不**按成员 git 仓拆分分组——子仓在树里只是普通文件夹。
- 项目目录在磁盘上缺失时，文件树视图改为给出「项目目录找不到」提示（见 `multi-repo-project`）。
- **点击文件项 MUST 在文件查看器中打开该文件**（见 `file-viewer`）：以该文件的绝对路径调用查看器的通用打开文件 API。点击**文件夹**仍只做展开/折叠，行为不变。

#### Scenario: 以项目目录为根展示
- **WHEN** 窗口绑定了项目且侧边栏文件树视图展开
- **THEN** 侧边栏以项目目录为根列出其下全部顶层文件与文件夹，不加任何成员仓分组层

#### Scenario: 多仓项目的子仓表现为普通文件夹
- **WHEN** 当前项目含多个 git 子仓
- **THEN** 这些子仓在文件树里作为项目目录下的普通文件夹出现，可像其它文件夹一样展开查看

#### Scenario: 点击文件打开文件查看器
- **WHEN** 用户在文件树里点击某个文件项
- **THEN** 文件查看器以该文件路径打开它（展开浮层并新增/聚焦对应标签）

#### Scenario: 点击文件夹仅展开折叠
- **WHEN** 用户在文件树里点击某个文件夹项
- **THEN** 该文件夹展开或折叠，不打开文件查看器
