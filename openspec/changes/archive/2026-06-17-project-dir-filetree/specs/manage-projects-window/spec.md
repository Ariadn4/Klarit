## MODIFIED Requirements

### Requirement: 右侧品牌与打开本地项目

管理项目窗口右侧 SHALL 在上方显示 Klarit 品牌标识与应用版本号，下方仅提供一个「打开本地项目」入口。点击「打开本地项目」MUST 让用户选择一个本地目录并按现有导入/打开流程打开它，其后续窗口落点遵循统一打开路由。当所选目录自身非 git、其下含多个 git 子仓时，系统 MUST 直接组建并打开多仓项目（与主窗口导入一致，不再提示需从主窗口侧边栏导入）。版本号 MUST 取自应用的实际版本（`package.json` version）。

#### Scenario: 显示品牌与版本号
- **WHEN** 用户打开管理项目窗口
- **THEN** 右侧上方显示 Klarit 品牌标识与当前应用版本号

#### Scenario: 打开本地项目
- **WHEN** 用户点击右侧的「打开本地项目」并选择一个本地目录
- **THEN** 系统按导入/打开流程打开该目录对应的项目，并按统一窗口路由决定落点

#### Scenario: 打开含多子仓的目录直接组建多仓项目
- **WHEN** 用户在「打开本地项目」中选择一个自身非 git、其下含多个 git 子仓的目录
- **THEN** 系统直接组建多仓项目并打开它，关闭管理项目窗口，不弹任何确认或提示
