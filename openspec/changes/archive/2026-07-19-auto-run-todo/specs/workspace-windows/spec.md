## MODIFIED Requirements

### Requirement: 在新窗口打开项目

当用户从项目切换器、或从管理项目窗口选择一个项目时，系统 SHALL 按如下优先级决定打开落点：

- 该项目**已有一个打开着的窗口** → 把那个窗口**聚焦置前**，不新建窗口（适用于任意已绑定该项目的窗口，不限于当前窗口）。
- 否则，存在一个**未绑定**任何项目的空状态窗口（例如 registry 有项目但无会话可恢复时的首启窗口）→ 在**那个空窗口**打开该项目（绑定并显示）。
- 否则（无可复用的空窗口）→ 在**新窗口**打开所选项目，而不覆盖任何已绑定窗口正在显示的项目。

每个窗口 MUST 绑定恰好一个项目。

当系统把一个**既有窗口**（空状态窗口）绑定到项目时，MUST **通知该窗口的渲染层重启视图**——离开空状态、拉取并显示新绑定项目的看板/卡/激活工作流。此通知 MUST 独立于**发起该动作的窗口**：即便绑定是从**另一个窗口**（如管理项目窗口）发起、被绑定的窗口并非当前聚焦窗口，被绑定窗口仍 MUST 刷新到新项目，不得停留在空状态（空屏）。新开窗口无需此通知——它加载即读到所绑项目。

#### Scenario: 该项目已有窗口则聚焦置前
- **WHEN** 用户选择的项目已有一个打开着的窗口
- **THEN** 系统聚焦那个窗口并置前，不新建窗口

#### Scenario: 空状态窗口选项目在本窗口打开并显示
- **WHEN** 该项目尚无打开窗口，存在一个未绑定的空状态窗口，用户选择项目 A
- **THEN** 系统把项目 A 绑定到该空窗口，**并通知其渲染层刷新到项目 A 的视图**（离开空状态），不新建窗口

#### Scenario: 从管理项目窗口选项目，被复用的空窗口刷新显示
- **WHEN** 存在一个未绑定的空状态窗口，用户在**管理项目窗口**里点选项目 A（发起窗口≠被绑定窗口）
- **THEN** 系统把项目 A 绑定到那个空窗口并聚焦它，**该空窗口渲染层刷新到项目 A**、不空屏；管理项目窗口随后关闭

#### Scenario: 导入新项目复用空窗口时刷新显示
- **WHEN** 用户导入一个新项目，且当前存在可复用的空状态窗口
- **THEN** 系统把新项目绑定到该空窗口，**并通知其渲染层刷新显示新项目**，不停留在空状态

#### Scenario: 已绑定窗口选另一个项目开新窗口
- **WHEN** 该项目尚无打开窗口，无可复用的空窗口，用户选择项目 B
- **THEN** 系统打开一个绑定项目 B 的新窗口（其加载即显示项目 B），原有已绑定窗口不受影响

#### Scenario: 选择当前项目不重复开窗
- **WHEN** 用户选择当前窗口已绑定的项目
- **THEN** 系统不新建窗口，将该窗口聚焦置前
