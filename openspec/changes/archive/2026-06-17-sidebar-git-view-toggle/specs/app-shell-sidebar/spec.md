## ADDED Requirements

### Requirement: 侧边栏顶部「文件树 / git」视图切换

侧边栏 SHALL 在顶部提供一行视图切换区，含两个 icon：文件夹 icon（文件树视图）与 git icon（git 视图）。点击对应 icon 在两态间切换，当前选中态的 icon MUST 有明确的选中视觉（如高亮）。视图模式**默认为文件树视图**，且 MUST 按窗口持久化，下次打开该窗口时恢复上次的视图模式。

#### Scenario: 默认展示文件树视图

- **WHEN** 用户首次打开一个绑定项目的窗口且侧边栏展开
- **THEN** 视图切换区的文件夹 icon 处于选中态，侧边栏展示文件树视图

#### Scenario: 点击 git icon 切到 git 视图

- **WHEN** 用户在文件树视图下点击 git icon
- **THEN** git icon 变为选中态，侧边栏内容切换为 git 视图

#### Scenario: 点击文件夹 icon 切回文件树视图

- **WHEN** 用户在 git 视图下点击文件夹 icon
- **THEN** 文件夹 icon 变为选中态，侧边栏内容切换回文件树视图

#### Scenario: 视图模式跨会话保持

- **WHEN** 用户切到 git 视图后关闭软件并重新打开该窗口
- **THEN** 侧边栏恢复为 git 视图

## MODIFIED Requirements

### Requirement: 当前项目目录文件树

当窗口已绑定一个项目且侧边栏处于**文件树视图**时，侧边栏 SHALL 展示该项目的目录文件树，文件夹可展开/折叠以查看其子项。文件树 MUST 反映磁盘上的实际内容，对目录内的增删改在合理时延内更新。git 视图下的展示由 `sidebar-git-view` 能力定义，本要求只约束文件树视图。

- 项目仅含一个成员仓时，侧边栏直接展示该仓主目录下的所有文件与文件夹（与扩展前一致）。
- 项目含多个成员仓时，侧边栏以每个成员仓为顶层分组（显示仓名，有 git 时附当前分支），各成员仓的目录树挂在其分组之下；每个成员仓的内容变更各自监听、各自更新。

#### Scenario: 单仓项目展示主目录

- **WHEN** 窗口绑定的项目仅含一个成员仓且侧边栏处于文件树视图
- **THEN** 侧边栏直接列出该成员仓主目录下的全部顶层文件与文件夹，不加分组层

#### Scenario: 多仓项目按成员仓分组展示

- **WHEN** 窗口绑定的项目含多个成员仓且侧边栏处于文件树视图
- **THEN** 侧边栏为每个成员仓显示一个顶层分组，展开分组可见该仓主目录的文件与文件夹

#### Scenario: 展开文件夹查看子项

- **WHEN** 用户点击文件树中的一个文件夹
- **THEN** 该文件夹展开并列出其直接子项

#### Scenario: 磁盘变更后同步

- **WHEN** 任一成员仓目录下新增、删除或重命名了文件
- **THEN** 对应成员仓的文件树在监听到变更后更新以反映最新内容
