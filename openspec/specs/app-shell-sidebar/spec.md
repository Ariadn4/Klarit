## Requirements
### Requirement: 可折叠的左侧栏

应用主窗口 SHALL 在左侧渲染一个侧边栏，并在顶栏提供一个开关按钮：展开时显示 `panel-left-close` 图标、折叠时显示 `panel-left-open` 图标，点击在两态间切换。侧边栏的折叠/展开状态 MUST 按窗口持久化，下次打开该窗口时恢复。

#### Scenario: 点击顶栏按钮折叠侧边栏
- **WHEN** 侧边栏处于展开状态，用户点击顶栏的 `panel-left-close` 按钮
- **THEN** 侧边栏收起，按钮图标变为 `panel-left-open`，主内容区占满窗口宽度

#### Scenario: 点击顶栏按钮展开侧边栏
- **WHEN** 侧边栏处于折叠状态，用户点击顶栏的 `panel-left-open` 按钮
- **THEN** 侧边栏重新出现，按钮图标变为 `panel-left-close`

#### Scenario: 折叠状态跨会话保持
- **WHEN** 用户在折叠侧边栏后关闭软件并重新打开
- **THEN** 该窗口的侧边栏仍为折叠状态

### Requirement: 侧边栏顶部「文件树 / git」视图切换

侧边栏 SHALL 在顶部提供一行视图切换区，含两个 icon：文件夹 icon（文件树视图）与 git icon（git 视图）。点击对应 icon 在两态间切换，当前选中态的 icon MUST 有明确的选中视觉（如高亮）。视图模式**默认为文件树视图**，且 MUST 按窗口持久化，下次打开该窗口时恢复上次的视图模式。

#### Scenario: 默认展示文件树视图

- **WHEN** 用户首次打开一个绑定项目的窗口且侧边栏展开
- **THEN** 视图切换区的文件夹 icon 处于选中态，侧边栏展示文件树视图

#### Scenario: 点击 git icon 切到 git 视图

- **WHEN** 用户在文件树视图下点击 git icon
- **THEN** git icon 变为选中态，侧边栏内容切换为 git 视图

#### Scenario: 点击文件夹 icon 切回文件树视图

- **WHEN** 用户在 git 视图下点击文件夹 icon
- **THEN** 文件夹 icon 变为选中态，侧边栏内容切换回文件树视图

#### Scenario: 视图模式跨会话保持

- **WHEN** 用户切到 git 视图后关闭软件并重新打开该窗口
- **THEN** 侧边栏恢复为 git 视图

### Requirement: 当前项目目录文件树

当窗口已绑定一个项目时，侧边栏的文件树视图 SHALL 以该项目的**项目目录**为根，像资源管理器一样直接列出该目录下的全部文件夹与文件，文件夹可展开/折叠以查看其子项。文件树 MUST 反映磁盘上的实际内容，对目录内的增删改在合理时延内更新。

- 无论项目含一个还是多个成员仓，文件树都以项目目录为唯一根，**不**按成员 git 仓拆分分组——子仓在树里只是普通文件夹。
- 项目目录在磁盘上缺失时，文件树视图改为给出「项目目录找不到」提示（见 `multi-repo-project`）。
- **点击文件项 MUST 在文件查看器中打开该文件**（见 `file-viewer`）：以该文件的绝对路径调用查看器的通用打开文件 API。点击**文件夹**仍只做展开/折叠，行为不变。

#### Scenario: 以项目目录为根展示
- **WHEN** 窗口绑定了项目且侧边栏文件树视图展开
- **THEN** 侧边栏以项目目录为根列出其下全部顶层文件与文件夹，不加任何成员仓分组层

#### Scenario: 多仓项目的子仓表现为普通文件夹
- **WHEN** 当前项目含多个 git 子仓
- **THEN** 这些子仓在文件树里作为项目目录下的普通文件夹出现，可像其它文件夹一样展开查看

#### Scenario: 点击文件打开文件查看器
- **WHEN** 用户在文件树里点击某个文件项
- **THEN** 文件查看器以该文件路径打开它（展开浮层并新增/聚焦对应标签）

#### Scenario: 点击文件夹仅展开折叠
- **WHEN** 用户在文件树里点击某个文件夹项
- **THEN** 该文件夹展开或折叠，不打开文件查看器

#### Scenario: 展开文件夹查看子项
- **WHEN** 用户点击文件树中的一个文件夹
- **THEN** 该文件夹展开并列出其直接子项

#### Scenario: 磁盘变更后同步
- **WHEN** 项目目录下新增、删除或重命名了文件
- **THEN** 文件树在监听到变更后更新以反映最新内容

### Requirement: 底部项目切换器

侧边栏底部 SHALL 有一个项目切换器。当存在已导入项目时，它显示当前项目名；点击弹出子菜单，列出所有已导入项目（当前项目带勾选标记），并在子菜单内提供「管理项目…」入口。当从未导入过任何项目时，切换器 MUST 改为显示「导入新项目」按钮。「管理项目…」MUST 可点击，点击打开管理项目窗口（见 `manage-projects-window`）。

注册表变更 MUST **实时广播到所有已开窗口**：在管理项目窗口移除/导入项目后，各窗口的切换器子菜单与项目状态 MUST 立即反映注册表当前内容（被移除的项目不再出现在子菜单里），不需要重启应用。

#### Scenario: 已有项目时显示当前项目名
- **WHEN** 窗口绑定了某项目
- **THEN** 切换器按钮显示该项目名

#### Scenario: 弹出子菜单列出全部项目
- **WHEN** 用户点击切换器按钮
- **THEN** 弹出子菜单，列出所有已导入项目，当前项目带勾选标记，菜单内含「管理项目…」入口

#### Scenario: 从未导入项目时显示导入入口
- **WHEN** 软件尚无任何已导入项目
- **THEN** 切换器显示「导入新项目」按钮，点击进入导入流程

#### Scenario: 点击「管理项目…」打开管理窗口
- **WHEN** 用户打开切换器子菜单并点击「管理项目…」
- **THEN** 系统打开管理项目窗口（其布局与行为见 `manage-projects-window`）

#### Scenario: 管理窗移除项目后子菜单即时同步
- **WHEN** 项目在管理项目窗口被移除，而另一窗口开着切换器可用状态
- **THEN** 该窗口收到注册表变更广播并刷新：子菜单不再列出被移除项目；若被移除的是当前项目，窗口回到未绑定空态

### Requirement: 侧边栏宽度可拖动调整

侧边栏 SHALL 提供一条位于其右边缘的可拖动分隔条，用户拖动它即可改变侧边栏宽度，主内容区相应让出或占用空间。拖动时分隔条 SHALL 给出可拖动的视觉与光标反馈（如 `col-resize` 光标）。侧边栏宽度 MUST 被约束在一个最小值与最大值之间：不得小于能容纳基本内容的最小宽度，也不得大于窗口宽度的一个合理上限，超出范围的拖动被钳制到边界值。调整后的宽度 MUST 按窗口持久化，下次打开该窗口时恢复到用户上次设置的宽度。

折叠与宽度互不破坏：折叠时整条侧边栏（含分隔条）隐藏；再次展开时 SHALL 恢复到用户上次设置的宽度，而非重置为默认宽度。

#### Scenario: 拖动分隔条加宽侧边栏

- **WHEN** 侧边栏处于展开状态，用户按住其右边缘的分隔条并向右拖动
- **THEN** 侧边栏实时变宽，主内容区相应变窄，松开后停在拖动到的宽度

#### Scenario: 拖动分隔条收窄侧边栏

- **WHEN** 用户按住分隔条并向左拖动
- **THEN** 侧边栏实时变窄，主内容区相应变宽

#### Scenario: 宽度被钳制在最小/最大之间

- **WHEN** 用户把分隔条拖到小于最小宽度或大于最大宽度的位置
- **THEN** 侧边栏宽度被钳制在最小值或最大值，不会更窄或更宽

#### Scenario: 宽度跨会话保持

- **WHEN** 用户调整侧边栏宽度后关闭软件并重新打开该窗口
- **THEN** 侧边栏恢复到用户上次设置的宽度

#### Scenario: 折叠再展开后恢复用户宽度

- **WHEN** 用户先调整过侧边栏宽度，随后折叠侧边栏，再重新展开
- **THEN** 侧边栏以用户上次设置的宽度重新出现，而非默认宽度

### Requirement: 顶栏收件箱入口

应用主窗口顶栏 SHALL 提供一个**收件箱入口**图标，与既有的侧边栏折叠开关并列。入口上 MUST 显示当前项目待决策条目数的徽标；条目数为 0 时 MUST NOT 显示徽标（不显示「0」，也不用置灰徽标占位）。

点击入口打开收件箱面板（内容与行为见 `decision-inbox`）；再次点击或点击面板外收起。入口的展开态 MUST 有明确的选中视觉，与顶栏其余按钮的视觉语言一致。

未绑定项目的窗口 MUST NOT 显示该入口（无项目即无运行、无决策）。

#### Scenario: 有待决策时入口带计数

- **WHEN** 当前项目有 2 个待决策
- **THEN** 顶栏收件箱入口显示徽标「2」

#### Scenario: 无待决策时不显示徽标

- **WHEN** 当前项目无待决策
- **THEN** 顶栏收件箱入口存在但不显示徽标

#### Scenario: 点击展开与收起

- **WHEN** 用户点击收件箱入口
- **THEN** 收件箱面板展开、入口呈选中态；再次点击收起

#### Scenario: 未绑定项目不显示入口

- **WHEN** 窗口未绑定任何项目
- **THEN** 顶栏不渲染收件箱入口
